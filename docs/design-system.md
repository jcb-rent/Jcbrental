# JCB Rental Service — Design System v0.2

## Brand direction
Professional, dependable equipment-rental service. Corporate blue is primary, with restrained construction-yellow accents. Neutral surfaces, clear hierarchy, generous spacing and subtle borders create a modern premium experience.

## Typography and layout
DM Sans for UI and Manrope for headings; system sans-serif fallback. Responsive hero 42–66px, section titles 20–29px, body 12–14px, meta 9–11px. 4px spacing scale, responsive page gutters, 10–17px card radius, minimum 48px buttons and inputs.

## Interaction and accessibility
One clear primary action per screen. Destructive actions require confirmation. Show loading, empty, error, success and offline states. Preserve form input on validation errors. Demo actions must disclose simulation. Maintain contrast, support browser zoom, label controls and do not encode meaning by colour alone.

## Formatting
Currency INR (₹), Indian digit grouping (₹1,25,000), India-local dates/times in production.
